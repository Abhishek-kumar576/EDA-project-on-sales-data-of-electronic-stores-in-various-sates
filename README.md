## Overview
A comprehensive exploratory data analysis project on sales data to uncover trends, patterns, and key business insights. The analysis is performed using Python in a Jupyter Notebook with data cleaning, visualization, and statistical summary.

## Dataset
- *sales data.xlsx*: Raw sales dataset containing transactions with fields like Date, Product, Category, Quantity, Price, Revenue, Region, etc.
- *sales_EDA_Project.ipynb*: Main Jupyter notebook with complete data analysis workflow.

## Key Analysis Steps
1. *Data Cleaning*: Handle missing values, remove duplicates, format date columns, and check data types.
2. *Descriptive Statistics*: Summary of sales, revenue, quantity, and average order value.
3. *Univariate Analysis*: Distribution of sales by product, category, and region using bar plots and histograms.
4. *Bivariate Analysis*: Relationship between variables like sales vs time, revenue vs quantity using scatter plots and line charts.
5. *Time Series Analysis*: Monthly and yearly sales trends to identify seasonality and growth patterns.
6. *Top Insights*: Identify top-selling products, best-performing regions, and peak sales periods.

## Tools & Libraries
- *Python 3.10+*
- *Pandas* - Data manipulation and cleaning
- *NumPy* - Numerical operations
- *Matplotlib & Seaborn* - Data visualization
- *Jupyter Notebook* - Interactive analysis environment
